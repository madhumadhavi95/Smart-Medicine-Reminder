#Smart Medicine Reminder

A smart medicine reminder application developed using Python, Flask, SQLite, HTML, CSS, and JavaScript. The project helps users manage their medicines, set reminders, and track their medication status easily.

Features

- 💊 Add medicines
- ⏰ Medicine reminders
- 📅 Date and time scheduling
- ✅ Mark medicine as taken
- 🗑️ Delete medicines
- 🔐 User registration and login
- 📊 Medicine dashboard
- 🔍 Search medicines
- 🔔 Reminder notifications
- 📱 User-friendly interface

Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
